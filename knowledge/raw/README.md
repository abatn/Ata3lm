# knowledge/raw/ — Rohdatenablage (Stufe 1 ERFAHRUNG)

> Lab-Prinzip MD-first. Alle Konventionen in dieser Datei sind per Auftrag
> gesetzt (Status: [Auftrag]), nicht quellenbelegt. Einzige Quellen: siehe
> `knowledge/lifecycle/experience.md`.

## Status [Auftrag]

Verzeichnis angelegt, wartet auf t=1-Befüllung.

Es liegen noch keine Rohdaten vor. Die erste Befüllung erfolgt im Durchlauf
t=1 per Skill `skills/collect-experience/SKILL.md`.

## Konvention: Dateiname [Auftrag]

- Je Quelle / Einheit eine Datei, unverändert gespeichert.
- Dateiname muss Quelle und Datum erkennbar machen
  (genaues Trennzeichen-Schema wird in t=1 per Auftrag festgelegt und dann
  hier dokumentiert; bis dahin: keine stillschweigende Normierung).
- Keine Umbenennung ohne Provenienz-Eintrag.

## Pflichtfelder je Einheit [Auftrag]

Jede abgelegte Einheit braucht:

1. **Quelle:** vollständiger Link zur offiziellen Quelle.
2. **Datum:** Erhebungs- / Abrufdatum (mit Zeitzone).
3. **Hash:** Integritäts-Hash der unveränderten Datei
   (Verfahren wird in t=1 per Auftrag festgelegt und dann hier dokumentiert).

Ohne diese drei Felder gilt die Einheit als nicht abgelegt.

## Guardrails [Auftrag]

1. Unverändert speichern — kein Kürzen, kein Paraphrasieren.
2. Jede Einheit mit Quellen-Link.
3. Keine Deutung, keine Wertung (Bewertung ist Compare).
4. ARIADNE Tier-1-Prinzip als Ablage-Prinzip:
   rohe Interaktionen unverändert festhalten
   (Prinzip-Übernahme: [Auftrag]; Prinzip-Inhalt: Quelle, siehe
   `knowledge/lifecycle/experience.md`).
