# Reflexion – Ablage für Denken (Stufe 5)

> Lab-Prinzip, MD-first. Jede Reflexion braucht Quellen-Prüfung + Quelle,
> sonst Status `rejected`.
> „Denken (Stufe 5)", „Self-Feedback", „Working Memory" sind
> Auftrags-Vokabular (keine Quellen-Behauptung).

## Status

Angelegt, wartet auf t=1. Noch keine Reflexions-Files vorhanden;
erste Reflexion erzeugt das erste File nach untenstehender Konvention.

## Konvention: Reflexions-Format

Ein File pro Reflexions-Durchlauf. Dateiname: `NNN-kurztitel.md`
(fortlaufend, z. B. `001-erste-reflexion.md`).

Pflichtfelder (ohne ein Feld kein Self-Feedback, Status `rejected`):

1. **Trajektorie (τ):** Was ist passiert (Aktionen, Beobachtungen)?
2. **Feedback (r):** Externes Signal / Evaluator-Output (mit Beleg)?
3. **Memory (mem):** Episodischer Memory-Stand vor der Reflexion?
4. **Prinzipienbasierte Reflexion:** Normative Regeln zur
   Fehlervermeidung (was vermeiden) – belegt: MARS.
5. **Prozedurale Reflexion:** Schritt-für-Schritt-Erfolgsstrategien
   (was wiederholen) – belegt: MARS.
6. **Synthese:** Optimierte Instruktionen aus EINEM Rekursionszyklus
   (Single-Recurrence-Cycle) – belegt: MARS.
7. **SEAA-Anteil (getrennt von MARS):** HMM-Parameter-Update statt nur
   Textspeicher; soziale Kontrast-Selbstmodellierung nur als
   beobachtbare Emergenz, keine Qualia-Claims.
8. **Quellen-Prüfung:** Pro Quelle – Link gültig? Inhalt geprüft?
   Auftrag vs. belegt?
9. **Quelle:** Ausschließlich zulässige Links (MARS Paper, MARS Code,
   SEAA, Reflexion-Anker – siehe unten), keine erfundenen Links.
10. **Status:** `belegt` (mit Quelle) oder `rejected` (mit Grund);
    Auftrags-Anteile als Auftrag markiert.
11. **Self-Feedback (sr):** `sr` aus (τ, r, mem), Weitergabe an
    Nicht-Kognition und Handeln (Stufen-Zuordnung als Auftrag markiert).
